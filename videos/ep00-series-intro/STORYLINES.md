# Ep 00 — Series intro (Vinit, Sr AI Architect)

Instagram Reel · 1080×1920 · 30 fps · ~55–60 s · arc: intro → the series map (Ch 0–7) → next episode (Ch 0: Inference)

## A. The life of one prompt (recommended)
**Device:** the object is the explanation · **Form:** an endless zoom
One prompt is sent from a phone, and the camera follows it inward. Each layer it passes through is a chapter of the series: the app, the model, the GPU, the software, the speed-up tricks, other media types and the production datacenter. It finishes back on the phone as the answer arrives. The viewer feels the whole syllabus as one journey, not a list.
- **First 2 s:** frame 0 shows a chat box with the prompt already typed and the line "What happens after you hit send?" Vinit's name card snaps in at 1 s.
- **Beats:** hook + "I'm Vinit, Sr AI Architect" (0–8 s) → send → zoom: App/Prereqs → tokens through transformer blocks (Models) → GPU die (Hardware) → kernels / vLLM / SGLang (Software) → quantization, speculative decoding, KV cache (Techniques) → image, voice, video (Modalities) → racks + autoscaling (Production) → zoom out, answer streams in (8–48 s) → "Next: Ep 1 — Inference" + follow (48–60 s)
- **Look:** an off-white ground with ink-black type and one electric-green accent for the prompt's path. Each world is drawn in technical-blueprint line art, with a big Inter Tight chapter number in each world.
- **Sound:** a minimal pulse at ~110 bpm that thickens with every zoom. One whoosh per zoom, rotating between 3 takes. A riser into an impact as the answer lands, then the music drops to the bed under the end card.

## B. The syllabus drop
**Device:** type carries the argument · **Form:** cut on the beat
Giant kinetic type and solid colour fields. Each chapter gets a full-screen number and title that slam in on the downbeat, followed by 2–3 of its real keywords (vLLM, Blackwell, EAGLE, KV cache, NIMs). It's punchy, fast and very Reels-native.
- **First 2 s:** frame 0 shows "8 chapters. 1 question: how does AI actually run?" in huge type, which then cuts to "I'm Vinit".
- **Beats:** hook → intro card → 0 · 1 · 2 · … · 7, one colour field each, ~4 s apiece → "Starting with Ep 1: Inference" → follow
- **Look:** a different saturated field per chapter and condensed display type that fills the frame edge to edge. No illustration.
- **Sound:** an upbeat 124 bpm track with every cut on a beat and a pop on each keyword chip. No whooshes.

## C. Build the stack (the bold one)
**Device:** a number lands / object as explanation · **Form:** one frame that rebuilds
A single frame that never cuts. Layers drop onto an empty floor one by one: Hardware is the foundation, then Software, Models, Techniques, Modalities and Production on top, until they form a complete inference stack. The stack then turns and becomes a server rack. Chapter 0, "Inference", is the slot left glowing in the middle, waiting to be filled.
- **First 2 s:** frame 0 is the finished stack, already built (the result first). It then shatters back to an empty floor while the line "I'm Vinit. Let's build this together." appears.
- **Beats:** finished stack → collapse → intro → 7 layers drop in, each labelled with 2 keywords → turns into a rack → empty "Inference" slot → "Ep 1" → follow
- **Look:** an isometric view with a dark slate ground and matte layer blocks, each a different muted tone. The green accent is used only on the Ep 1 slot.
- **Sound:** a slow build at 96 bpm with a weighty thud on each layer landing and the impact on the final rack.
